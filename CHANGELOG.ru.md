# История изменений

> **Язык:** Русский · [English changelog](CHANGELOG.md)

В этом файле перечислены все значимые изменения Samsung Alarm Clock Widget by Zucker.

Проект использует простую последовательную нумерацию версий. Версия 1.1 стала первым релизом, подписанным постоянным production-ключом.

## [1.2.0] — 2026-09-26

- Исправлено выравнивание текста в установленном виджете с учётом видимых границ символов: все девять положений теперь соответствуют превью в настройках, а при выравнивании по центру видимые отступы одинаковы.
- Снижена фоновая нагрузка: используются системные события изменения будильников и резервная проверка раз в минуту; чтение будильников пропускается при выключенном экране; неизменившийся кэш не перезаписывается; отрисованные кадры виджета используются повторно. Резервная проверка без пробуждения устройства возобновляет фактическую проверку после включения экрана.
- Снижена стоимость разбора диагностических данных Samsung без изменения правил выбора будильника.
- Полуночное обновление планируется только для виджетов, отображающих дату.
- После событий изменения Samsung Clock добавлена отложенная подтверждающая проверка, поскольку One UI может сообщить о далёком повторяющемся будильнике за несколько секунд до окончательной регистрации его записи.
- Исследованы и отклонены специфичные для Samsung события будильников: событие виджета Clock ограничено пакетом, а глобальное событие One UI недоступно фоновым получателям из манифеста. Поэтому виджет продолжает использовать стандартное событие Android вместе с резервной проверкой без пробуждения устройства.
- После обновления приложения поверх установленной версии кэш будильника обновляется, чтобы значение из старой версии не оставалось до следующей плановой проверки.

### Добавлено

- Полноценная адаптивная launcher-иконка с круглым и монохромным тематическим вариантами.
- Нативное превью виджета для поддерживаемых launcher-приложений.
- Русские и английские ресурсы с возможностью выбора языка приложения.
- Экран «О приложении и лицензии» с версией, ссылкой на репозиторий и сведениями о лицензиях.
- Проверка состояния разрешений внутри приложения, предупреждения и копируемые инструкции ADB.
- Apache License 2.0 и уведомления о сторонних компонентах Google Material Icons и Material Symbols.
- Формы GitHub Issues для сообщений об ошибках и отчётов о совместимости.
- Безопасный workflow GitHub Actions для lint, модульных тестов и debug-сборки без секретов production-подписи.
- Галерея скриншотов, руководство по участию в разработке, политика безопасности и более заметные ссылки поддержки.
- Приватные сообщения об уязвимостях для ответственного раскрытия проблем безопасности.

### Изменено

- Шрифт значка будильника заменён подмножеством, созданным из актуального официального исходника Google Material Symbols.
- Ресурсы Material Icons обновлены из официального источника.
- Улучшены описания для специальных возможностей, работа с клавиатурой и TalkBack, контраст текста и компоновка при максимальном системном размере шрифта.
- Добавлено сокращённое название под launcher-иконкой; полное название проекта сохранено на экране «О приложении» и в метаданных виджета.
- Результат отсутствия будильника больше не зависит от локализованного диагностического текста; алгоритм выбора будильника не изменён.

### Проверено

- Русский и английский интерфейсы на Samsung Galaxy S25 FE с One UI 8.5.
- Адаптивная и монохромная launcher-иконки, нативное превью виджета и максимальный системный размер шрифта.
- Предупреждения об отсутствующих разрешениях, восстановление разрешений и их сохранение после обновления поверх установленной версии.
- Ссылки на репозиторий, лицензию и уведомления о сторонних компонентах, открытие Samsung Clock и обновление виджета после изменения будильника.
- Установка production-сборки 1.2.0 поверх версии 1.1 с сохранением виджета, настроек и ADB-разрешений.

## [1.1] — 2026-09-26

### Изменено

- Временная debug-подпись заменена постоянным production-ключом.
- `versionCode` увеличен до `101`, `versionName` — до `1.1`.
- Добавлена безопасная локальная настройка release-подписи через исключённый из Git файл `keystore.properties`.
- В README добавлены заметная кнопка загрузки APK и подробная инструкция по установке.
- Задокументировано тестовое окружение Samsung Galaxy S25 FE с One UI 8.5.
- Добавлены сведения о совместимости, конфиденциальности, устранении проблем и обновлении.

### Проверено

- Подпись release APK и отпечаток постоянного сертификата.
- Установка версии 1.1 поверх существующей установки с production-подписью.
- Сохранение виджета, его настроек и разрешений `DUMP`, `PACKAGE_USAGE_STATS` и `GET_USAGE_STATS` после обновления поверх установленной версии.

### Важная информация об обновлении

- Публичная версия 1.0 использовала временную debug-подпись и не может быть напрямую обновлена до 1.1.
- Пользователям версии 1.0 необходимо один раз удалить её, установить 1.1 и повторно выдать требуемые ADB-разрешения.
- Релизы начиная с 1.1 обновляются поверх без повторения этой миграции.

## [1.0] — 2026-09-26

### Добавлено

- Первый публичный релиз.
- Настраиваемый виджет часов для домашнего экрана с отображением времени, даты и следующего будильника.
- Определение будильников Samsung Clock с фильтрацией посторонних системных событий Android и расписаний Samsung Modes and Routines.
- Автоматическое фоновое обновление после изменения будильника и перезагрузки телефона.
- Настраиваемые цвета, шрифты, размеры текста, выравнивание, тень, форматы времени и даты, а также часовой пояс.
- Настраиваемое действие по нажатию на виджет, включая открытие Samsung Clock или другого выбранного приложения.
- Повторная настройка виджета через меню долгого нажатия One UI.
- Оптимизированная release-сборка с сокращением ресурсов и минификацией кода.

### Известное ограничение

- Эта версия была подписана временным debug-ключом.

## Сборки до версии 1.0

### Определение будильника

- Реализовано прямое чтение записей будильников Samsung Clock через `dumpsys alarm`.
- Добавлен разбор записей Samsung, разделённых между несколькими строками вывода.
- Добавлена целевая диагностика записей `com.sec.android.app.clockpackage` и `EXPLICIT_ALARM_ALERT`.
- Добавлена фильтрация, не позволяющая Modes and Routines и посторонним запланированным событиям подменять настоящий следующий будильник.
- Добавлена поддержка повторяющихся будильников, запланированных на несколько дней вперёд.
- Добавлены кэш состояния будильника и периодическая проверка.

### Разрешения и надёжность

- Добавлено разрешение `DUMP`, необходимое для чтения системных записей будильников.
- Добавлены `PACKAGE_USAGE_STATS` и соответствующий AppOp `GET_USAGE_STATS`, необходимые на проверенной версии Android/One UI.
- Подтверждено сохранение разрешений и работы виджета после обычной перезагрузки телефона.
- Подтверждена работа без root, Shizuku и постоянно подключённого компьютера.

### Виджет и интерфейс

- Первоначальная текстовая компоновка заменена растровой отрисовкой для единообразия шрифтов, размеров, теней и выравнивания.
- Добавлены девять положений выравнивания и несколько шрифтов часов.
- Добавлены настройки внешнего вида времени, даты, будильника и фона.
- Добавлен выбор приложения или ярлыка, открываемого по нажатию на виджет.
- Добавлены видимость пакета Samsung Clock и надёжный запуск приложения.
- Добавлена повторная настройка виджета через меню долгого нажатия One UI.
- Основное поведение и структура настроек Digital Clock Widget от Maize / EZI Studio Inc. независимо воссозданы без использования его исходного кода.
