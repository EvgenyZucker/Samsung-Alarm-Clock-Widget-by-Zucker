# Samsung Alarm Clock Widget 1.0

[Страница релиза](https://github.com/EvgenyZucker/Samsung-Alarm-Clock-Widget-by-Zucker/releases/tag/v1.0) · [Актуальная русская документация](../../README.ru.md) · [Последний стабильный релиз](https://github.com/EvgenyZucker/Samsung-Alarm-Clock-Widget-by-Zucker/releases/latest)

Первый публичный релиз Samsung Alarm Clock Widget by Zucker.

## Возможности

- Настраиваемый цифровой виджет часов.
- Отображение ближайшего будильника Samsung Clock.
- Настройки цветов, шрифта, формата времени и даты.
- Оптимизированная фоновая проверка.

Полный перечень изменений находится в [русской истории изменений](../../CHANGELOG.ru.md#10--2026-09-26).

> [!WARNING]
> APK версии 1.0 подписан временным debug-ключом. Он не может быть обновлён напрямую до версии 1.1 или новее.

## Переход на актуальную версию

1. При необходимости удалите виджет версии 1.0 с домашнего экрана.
2. Удалите приложение версии 1.0.
3. Установите APK из [последнего стабильного релиза](https://github.com/EvgenyZucker/Samsung-Alarm-Clock-Widget-by-Zucker/releases/latest).
4. Повторно выдайте необходимые ADB-разрешения.
5. Добавьте и настройте виджет заново.
