# Samsung Alarm Clock Widget 1.2.0

[Скачать production APK](https://github.com/EvgenyZucker/Samsung-Alarm-Clock-Widget-by-Zucker/releases/download/v1.2.0/Samsung-Alarm-Clock-Widget-by-Zucker-v1.2.0.apk) · [Страница релиза](https://github.com/EvgenyZucker/Samsung-Alarm-Clock-Widget-by-Zucker/releases/tag/v1.2.0) · [Полная русская документация](../../README.ru.md)

Версия 1.2.0 — первый функциональный релиз после перехода на постоянную production-подпись в версии 1.1.

## Основные изменения

- Добавлена полноценная адаптивная launcher-иконка с круглым и монохромным тематическим вариантами.
- Добавлено нативное превью виджета для поддерживаемых launcher-приложений One UI.
- Добавлены русский и английский интерфейсы, включая выбор языка приложения.
- Добавлен экран «О приложении и лицензии», диагностика разрешений и копируемые ADB-команды.
- Исправлены все девять вариантов выравнивания текста. При выравнивании по центру видимый контент имеет одинаковые отступы.
- Повышена надёжность обновления повторяющихся будильников, запланированных на несколько дней вперёд.
- Снижена фоновая нагрузка: резервная проверка выполняется примерно раз в минуту при включённом экране, не читает будильники при выключенном экране и запускает отложенную проверку после его включения.
- Добавлены Apache License 2.0, уведомления о сторонних компонентах, формы Issues, CI, руководство для участников и политика безопасности.

Полный перечень изменений находится в [русской истории изменений](../../CHANGELOG.ru.md#120--2026-09-26).

## Обновление с версии 1.1 или новее

Установите APK 1.2.0 поверх существующего приложения. **Не удаляйте предыдущую версию.** Виджет, его настройки и выданные через ADB разрешения сохранятся.

Обновление production-сборки 1.1 до 1.2.0 проверено на Samsung Galaxy S25 FE с One UI 8.5.

## Переход с публичной версии 1.0

Публичная версия 1.0 была подписана временным debug-ключом и не может быть обновлена напрямую. Один раз удалите версию 1.0, установите 1.2.0, повторно выдайте ADB-разрешения и добавьте виджет заново.

Подробные шаги приведены в разделах [«Обновление приложения»](../../README.ru.md#обновление-приложения) и [«Обновление завершается ошибкой подписи»](../../README.ru.md#обновление-завершается-ошибкой-подписи).
