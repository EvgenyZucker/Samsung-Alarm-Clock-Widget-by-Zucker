Версия 1.1 — первый релиз с постоянной production-подписью, используемой этой и последующими версиями.

> [!IMPORTANT]
> Публичная версия 1.0 использовала временную debug-подпись. Android не может обновить её напрямую до версии 1.1. Перед установкой выполните описанную ниже одноразовую миграцию.

## Основные изменения

- Постоянная production-подпись.
- Проверенное обновление между production-сборками поверх установленной версии.
- Сохранение настроек виджета и ADB-разрешений при обновлении с версии 1.1 или новее.
- Подробные инструкции по установке, разрешениям и устранению проблем.
- Проверка на Samsung Galaxy S25 FE с One UI 8.5.

Полный перечень изменений находится в [русской истории изменений](../../CHANGELOG.ru.md#11--2026-09-26).

## Новая установка

1. Скачайте APK по ссылке выше.
2. Установите его на устройство Samsung.
3. Выдайте необходимые ADB-разрешения по [русской инструкции](../../README.ru.md#подробная-установка-и-настройка).
4. Добавьте виджет через меню виджетов One UI.

## Переход с публичной версии 1.0

1. При необходимости удалите старый виджет с домашнего экрана.
2. Удалите версию 1.0.
3. Установите версию 1.1.
4. Повторно выдайте необходимые ADB-разрешения.
5. Заново добавьте и настройте виджет.

Удаление версии 1.0 удалит экземпляр виджета, настройки и выданные разрешения. Эта миграция требуется только один раз.

## Обновление с версии 1.1 или новее

Устанавливайте более новую production-сборку поверх существующего приложения. Не удаляйте предыдущую версию: так сохраняются виджет, настройки и ADB-разрешения.
