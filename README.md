# Samsung Alarm Clock Widget by Zucker

Настраиваемый Android-виджет цифровых часов с отображением ближайшего будильника Samsung Clock.

## Возможности

- отображение времени, даты и ближайшего будильника;
- настройка цветов, шрифта, размера и выравнивания;
- выбор формата времени и даты;
- поддержка выбранного часового пояса;
- настраиваемое действие по нажатию на виджет;
- оптимизированная фоновая проверка изменений будильника.

## Версия

Текущая версия: **1.0** (`versionCode 100`).

## Сборка

Проект требует Android SDK 36 и совместимый JDK. Для создания оптимизированного release APK:

```powershell
.\gradlew.bat clean assembleRelease
```

APK создаётся в `app/build/outputs/apk/release/app-release.apk`.

> Текущая release-конфигурация использует debug-подпись и предназначена для тестовой установки. Для долговременного распространения следует настроить собственный production signing key.
